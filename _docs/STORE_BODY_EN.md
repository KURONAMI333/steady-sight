Reduce abrupt first-person camera motion with an edge vignette, smoother steps and minecart slopes, and one-time comfort settings.

Steady Sight bundles several independently controlled changes for players who experience motion sickness or discomfort in first-person games. It is not a treatment, and results vary from person to person.

## Features

- **Edge vignette** — keeps the edges of the screen dimmed to provide a fixed visual frame. Choose Off, Subtle, Standard, or Strong.
- **Smoother vertical camera movement** — eases the camera over one-block steps and minecart slope transitions without changing position, movement, collision, or physics.
- **One-time vanilla settings** — disables view bobbing, screen distortion, FOV effects, damage tilt, and auto-jump on first use. It also raises FOV to 90 when the existing value is lower. Settings you later change are not overwritten again.
- **One-time settings for supported mods** — caps Blueprint screen shake and adjusts relevant Punchy and SmoothGUI motion settings when those mods are present. Deliberate changes made afterward are preserved.

## Settings

NeoForge provides a config screen and file. Forge provides the same config file without a built-in screen. Fabric uses the default settings: Standard vignette with the other features enabled.

On NeoForge and Forge, the vignette strength and each automatic feature can be controlled separately. The vanilla-settings and other-mod-settings changes also have separate toggles.

Steady Sight does not add camera rotation inertia or change render distance or frame pacing. If another installed mod already smooths steps or minecart slopes, disable the overlapping Steady Sight feature.

The config screen text and tooltips are available in nine languages. Translations use a machine-generated baseline; corrections are welcome through GitHub.
